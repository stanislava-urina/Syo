Telegram Bot для записи в очередь (Queue Management System)

Telegram бот для интеграции с системой управления очередью (QMS). Позволяет пользователям записываться в живую очередь или на конкретное время, просматривать историю запписей и получать напоминания.

Функциональность

Для пользователей:
- Регистрация через отправку контакта (номер телефона)
- Запись в живую очередь - получение талона с примерным временем ожидания
- Запись на конкретное время - выбор доступных слотов
- Выбор категорий услуг (при необходимости)
- Мои автомобили - добавление и управление автомобилями (до 5 штук)
- История записей - просмотр активных и завершенных записей
- Отмена записи - возможность отменить активную запись
- Напоминания - уведомление за 2 часа до записи
- Ограничение на активные записи - не более 2 активных записей на пользователя

Для администраторов:
- Панель администратора (доступ по команде /admin)
- Управление бан-листом - блокировка пользователей по ID
- Массовая рассылка сообщений всем пользователям
- Редактирование информации - тексты "О компании" и "Контакты"
- Уведомления о новых записях - моментальное оповещение всех админов
- Уведомления об отменах - информация об отмененных записях

Установка и запуск

Требования:
- Python 3.8+
- Установленные зависимости

Установка зависимостей:
pip install aiogram aiohttp requests

Файлы конфигурации:

Бот использует текстовые файлы для хранения данных:
- admin.txt - список ID администраторов (по одному на строку)
- banned.txt - список забаненных пользователей
- registrated.txt - список зарегистрированных пользователей (ID:телефон)
- Hi.txt - приветственное сообщение для команды /start
- Abot.txt - информация о компании
- contacts.txt - контактная информация
- history_{user_id}.json - история записей пользователя
- vehicles_{user_id}.json - список автомобилей пользователя

Настройка токенов:

В коде необходимо заменить:
BOT_TOKEN = "ваш_токен_бота"
API_TOKEN = "ваш_токен_api_qms"

Запуск:
python bot.py

Структура проекта:

bot.py              # Основной файл бота
Read.py             # Модуль для работы с файлами
admin.txt           # Список администраторов
banned.txt          # Список забаненных
registrated.txt     # Зарегистрированные пользователи
Hi.txt              # Приветственное сообщение
Abot.txt            # Информация о компании
contacts.txt        # Контактная информация

vehicles_*.json     # Файлы автомобилей пользователей

Команды бота

Пользовательские:
- /start - начало работы, приветствие
- /help - показать главное меню

Административные:
- /admin - вход в панель администратора

Основные функции

Регистрация:
Пользователь отправляет свой контакт, бот сохраняет номер телефона и предоставляет доступ к функционалу.

Мои автомобили:
Пользователь может добавлять несколько автомобилей для записи на время. Автомобили сохраняются и могут быть выбраны при записи.

Запись на время:
1. Выбор услуги из списка
2. Выбор категорий (опционально)
3. Выбор доступного временного слота
4. Выбор или добавление автомобиля
5. Подтверждение записи
6. Получение номера талона

Живая очередь:
1. Выбор услуги
2. Выбор автомобиля
3. Автоматическая регистрация в очереди
4. Получение номера талона и примерного времени ожидания

История записей:
- Отображение активных и завершенных записей
- Возможность отмены активных записей
- Автоматическое обновление статусов

Лимиты и ограничения:
- Максимум 2 активные записи на одного пользователя
- Живая очередь и запись на время считаются в общем лимите
- Напоминания отправляются только для записей на время (за 2 часа)

Логирование:

Бот ведет подробное логирование в файл bot.log с ротацией:
- Максимальный размер файла: 5 МБ
- Количество хранимых файлов: 5
- Уровень логирования: INFO

Обработка ошибок:
- Автоматическое восстановление при сбоях API
- Тестовые ответы при недоступности сервера
- Защита от поврежденных файлов истории
- Обработка 404 ошибок API как ошибок логики

Безопасность:
- Проверка прав доступа для административных функций
- Бан-лист для блокировки нежелательных пользователей
- Валидация вводимых данных (номер автомобиля)
- Защита от превышения лимита записей
- Защита от повторной регистрации одного пользователя

Прокси:

Бот поддерживает работу через прокси (настраивается в коде):
PROXY_URL = "http://147.161.210.140:8800"

Возможные проблемы и решения:

Пользователь не регистрируется:
- Проверить наличие файла registrated.txt
- Проверить права на запись в директорию

Ошибки API:
- Проверить токен API
- Проверить доступность API сервера
- Посмотреть логи в bot.log

Бот не отвечает:
- Проверить интернет-соединение
- Проверить работу прокси
- Перезапустить бота

Запись не создается:
- Проверить количество активных записей (не более 2)
- Убедиться, что добавлен автомобиль
- Проверить наличие свободных слотов
